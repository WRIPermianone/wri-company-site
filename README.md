# Warrior Race Investments — company homepage redesign

Self-contained static single-page site.

- `index.html` — full page markup
- `style.css` — design tokens + all component styles
- `base.css` — reset/accessibility base (shared with the WRI Permian 1 page)
- `app.js` — scroll reveal, sticky-header state, footer year
- `assets/` — images (see IMAGE-SOURCES.md)

Preview locally: `python3 -m http.server 8321` then open http://127.0.0.1:8321/
